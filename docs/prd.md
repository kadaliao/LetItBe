产品需求文档（PRD）

1. 产品概述

1.1 产品名称（暂定）
• 摆烂心法
• 英文占位名：Let It Be

1.2 产品一句话定义

一个在低能量状态下，帮助用户止损、缓冲、自我恢复的极简心理辅助 App。

1.3 产品核心价值
• 不鼓励努力
• 不制造内疚
• 不强行积极

只做一件事：
在人最撑不住的时候，说一句不废的话，并防止事情变得更糟。

⸻

2. 目标用户

2.1 核心用户画像
• 20–40 岁
• 长期处于高压 / 高自责环境
• 理性、克制、对“鸡汤”和“成功学”高度免疫

典型人群示例：
• 工程师 / 产品经理
• 长期熬夜的职场人
• 新手父母
• 情绪低谷但仍保持功能性的人

2.2 使用场景
• 晚上独处、刷手机但情绪低落
• 拖延严重，无法启动任务
• 自我否定、内心噪音过大
• 明确知道“该休息”，但又无法安心休息

⸻

3. 产品定位与边界

3.1 本产品不做的事情
• 不提供心理诊断
• 不替代心理咨询
• 不做打卡、自律、目标管理
• 不做社交、不做社区

3.2 本产品只做的事情
• 情绪缓冲
• 认知止损
• 极低成本行为引导

⸻

4. 产品结构（信息架构）

4.1 页面结构（MVP）1. Home / 主页 2. State Picker / 状态选择页 3. Card / 一屏内容页（核心）4. Favorites / 收藏页（可选但推荐）

⸻

5. 功能需求详述

5.1 Home / 主页

目的：
• 提供最快的“进入摆烂模式”的入口

页面元素：
• 主按钮：我想摆烂
• 快捷入口（可选）：
• 止损一下
• 别骂自己
• 睡前降噪

交互说明：
• 点击主按钮 → 进入状态选择页
• 快捷入口 → 直接进入对应标签的卡片页

⸻

5.2 State Picker / 状态选择页

目的：
• 用极低认知成本，对用户当前状态做粗分类，提高内容命中率

状态选项（固定 4 类）：
• 累（能量枯竭）
• 麻（麻木、空）
• 躲（拖延、逃避）
• 烦（焦虑、内心噪音）

交互说明：
• 单选
• 选中后立即进入卡片页
• 无“返回修改”强制流程

⸻

5.3 Card / 一屏内容页（核心）

目的：
• 在 5–10 秒内完成一次情绪缓冲

页面结构（固定）：
• 标题（1 行）
• 正文（4–7 行短句）
• 底部小字（1 行）
• 操作区（2 个按钮）
• 主按钮：止损一下
• 次按钮：换一条

行为说明：
• 换一条：同一状态标签内随机
• 禁止下拉刷新（避免成瘾式刷内容）

⸻

5.4 止损动作（MVP 级）

原则：
• 不追求完成
• 不追求成长
• 只防止进一步恶化

动作类型：
• 1–2 分钟呼吸 / 发呆计时
• 极简 checklist（喝水 / 洗脸）
• 纯提示型（提示后返回主页）

⸻

6. 内容系统设计

6.1 内容单位
• 每条内容 = 一张卡片

字段建议：
• id
• title
• body
• footer
• tags（累 / 麻 / 躲 / 烦）
• action_type
• is_favorited

6.2 内容风格约束（硬约束）
• 不使用命令句（不出现“你应该”）
• 不承诺结果（不保证变好）
• 不比较他人
• 不制造希望幻觉

⸻

7. 非功能性需求

7.1 技术原则
• 本地优先（无需账号）
• 离线可用
• 数据结构简单

7.2 隐私原则
• 不采集情绪数据
• 不上传使用行为
• 不做画像

⸻

8. 商业化（非 MVP）

建议路径：
• 免费完整版（建立信任）
• 后续可选：
• 一次性买断
• 打赏 / 支持型付费

不建议：
• 广告
• 连续订阅驱动型模式

⸻

9. 成功指标（定性优先）

MVP 阶段不追求 DAU / 留存最大化，重点观察：
• 是否在深夜被打开
• 是否被截图、转述

⸻

10. 风险与边界声明
    • App 明确声明：非医疗、非心理咨询工具
    • 当用户长期停留在“摆烂状态”相关内容时，应提供温和提示（非强制）

⸻

11. 版本规划（极简）

v1.0
• 核心 13 条内容
• 4 状态分类
• 手动触发

v1.1（可选）
• 内容扩充
• 夜间模式
• 更细粒度止损动作

⸻

备注：
这是一个“克制大于野心”的产品。
一旦开始追求活跃、留存、增长，它就会背离初衷。
