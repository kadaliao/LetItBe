# LetItBe 1.1 Release Notes

## zh-Hans
这次更新主要是内容大扩充：
- 四大模块内容库大幅增加，总量提升到 800 条。
- 新增“更毒舌”风格文案，覆盖累/麻/躲/烦四种状态。
- 优化卡片轮换体验，减少重复感。
- 保持离线可用与轻量体验。

## English
This update is focused on a major content expansion:
- Massive increase in the card library across all 4 mood modules, now 800 cards total.
- Added sharper, snarkier writing style options across all states.
- Improved card rotation to reduce immediate repeats.
- Keeps the same offline-first, lightweight experience.
